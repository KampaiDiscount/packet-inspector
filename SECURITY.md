# Security reporting

Use [GitHub private vulnerability reporting](https://github.com/KampaiDiscount/packet-inspector/security/advisories/new)
to report a suspected vulnerability. Do not put exploitation details,
credentials, raw captures or unredacted findings in a public issue.

Include the affected version, prerequisites, expected impact and a minimal
synthetic reproduction. Keep real assessment data out of the report whenever
possible. No response-time or backport guarantee is currently offered; check
the current release and default branch when determining affected versions.

Operational capture and privacy boundaries are documented in [README.md](README.md),
[COVERAGE.md](COVERAGE.md), [RELIABILITY.md](RELIABILITY.md) and [NOTICE.md](NOTICE.md).
